# LoginThreat – Login Activity Prediction Using Linear Regression

## About the Project
LoginThreat is a beginner-friendly machine learning project that predicts failed login activity using Linear Regression.

The project analyses authentication log data and predicts the number of failed login attempts within 5-minute intervals.

## Objectives
- Understand authentication log data.
- Analyse failed login activity.
- Perform data preprocessing and feature engineering.
- Build a Linear Regression model.
- Predict failed login counts.
- Evaluate model performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning Algorithm
**Linear Regression**

## Dataset
IAM Anomaly Detection Dataset 2026 (synthetic authentication logs).

Original dataset: https://github.com/KREONET/auth-anomaly-dataset

The dataset is included in this repository as a ZIP file.

## Project Files
- `LoginThreat.ipynb` – Google Colab notebook containing the complete Python code.
- `iam_anomaly_2026.zip` – Compressed dataset.
- `README.md` – Project documentation.

## Model Evaluation
The model is evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
